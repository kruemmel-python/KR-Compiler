# GUI-Cross-Test

Reproduzierbares Testprojekt für den mobilen VCPKG-Manifestmodus von KR IDE.

- `sdl3`: Fenster, Eingabe und Renderer
- `imgui`: Benutzeroberfläche
- Ziele: Android ARM64, Windows x64 und Linux x64

Der Android-Build verwendet die SDL3-Activity mit Touch- und Surface-Ereignissen und erzeugt eine signierte Runner-APK.

Die Android-App erzeugt dieselbe Struktur über **Menü → Neues GUI-Projekt**.
