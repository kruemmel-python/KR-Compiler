# KR Compiler Android IDE v4.0.0

Version 4.0 erweitert KR Compiler um vollständige Rust- und Go-Projekte für Android ARM64, Windows x64 und Linux x64.

## Neu

- Projektassistent für Rust Konsole, Rust GUI, Go Konsole und Go GUI
- integrierte Rust-, Cargo- und Go-Werkzeugkette
- automatische Erkennung von `Cargo.toml`, `go.mod`, `.rs`- und `.go`-Dateien
- Android-APKs, Windows-EXEs und Linux-ELF-Dateien aus demselben Projekt
- SDL3-GUI-Brücke für Rust und Go
- Dateiansicht und Editor-Unterstützung für Rust und Go
- aktualisierte Werkzeugprüfung und ausführbare Go-Werkzeuge nach dem Entpacken

## Geprüft

Auf einem RMX3853 wurden zwölf Sprach- und Zielkombinationen erfolgreich gebaut. Konsolenprogramme liefen auf Android, Windows und Ubuntu. Die Android- und Windows-GUI-Programme wurden gestartet; die Linux-GUI-Dateien wurden als x86-64-ELF geprüft und gestartet.

Das Release enthält die IDE-APK, drei aktualisierte Word-Dokumente und ein ZIP-Paket mit allen zwölf erzeugten Beispiel-Artefakten.
