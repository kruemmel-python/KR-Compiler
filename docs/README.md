# Aktuelle Dokumentation

Dieser Ordner enthält ausschließlich die Dokumentation des aktuellen
Projektstands. Die zentrale Referenz ist die
[vollständige Projektdokumentation](PROJECT_DOCUMENTATION.md).

| Dokument | Zweck |
|---|---|
| [PROJECT_DOCUMENTATION.md](PROJECT_DOCUMENTATION.md) | Gesamtarchitektur, Bedienung, Compiler, Build, Adaptive Compute, Tests und Grenzen |
| [USER_GUIDE.md](USER_GUIDE.md) | kompakter Arbeitsablauf für Anwender |
| [KR_UNIFIED_LANGUAGE_GUIDE.md](KR_UNIFIED_LANGUAGE_GUIDE.md) | Sprache, Typen, Sprachfusion und Projektformat |
| [ADAPTIVE_COMPUTE.md](ADAPTIVE_COMPUTE.md) | automatische Compute-Analyse und Runtime |
| [PORTABLE_LINUX_X64.md](PORTABLE_LINUX_X64.md) | Linux-Bundle, Offline-Regeln und Verifikation |
| [BUILD_ARTIFACTS.md](BUILD_ARTIFACTS.md) | aktuelle Release-Dateien und Prüfsummen |
| [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) | implementierter Stand und verbleibende Funktionsgrenzen |

## Pflegegrundsatz

Dokumente werden bei Änderungen unter ihrem dauerhaften Namen aktualisiert.
Es werden keine Kopien pro Version angelegt. Historische Release-Texte,
Prüfsummen und Binärdateien bleiben beim jeweiligen GitHub Release. Im
Repository verweist nur [`RELEASE_NOTES.md`](../RELEASE_NOTES.md) auf das
aktuelle Release.
